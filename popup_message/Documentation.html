PopUp Message System Documentation

Overview

Reusable JavaScript PopUp Message system for showing dynamic notifications like success, error, warning, info and custom messages with themes, icons and auto-dismiss functionality.

Features

  • Multiple message types (Success, Warning, Error, Info)
  • Custom message with image support
  • Auto dismiss with progress bar animation
  • Replace or stack messages
  • CSS variable based theme system
  • Interactive UI (hover animation + close button)

Quick Start

  1. Include your PopUp component file.
  2. Add #popUpContainer in HTML (optional).
  3. Create instance of popUpMassge.
  4. Call message methods as needed.

Usage Example

const pm = new popUpMassge(5000);

// Basic message
pm.createMassage("Hello User");

// Success message
pm.createSuccess("Data Saved Successfully");

// Error message
pm.createError("Something went wrong", false, 3000);

// Warning
pm.createWarning("Check your input");

// Info
pm.createInfo("System update available");

Message with Image

pm.createMessageWithImage(
 "Profile Updated",
 "./img/profile.jpg",
 "User Image"
);

Auto Timeout

// Set default timeout for all messages
pm.setDefultAutoTimeOutForAll(10000);

// Override per message
pm.createSuccess("Saved", false, 3000);

Message Method Parameters

  • msg → Message text (string)
  • replace → Replace previous messages (true/false)
  • removeTime → Auto remove time in ms

Available Methods

  • createMassage() → General message
  • createSuccess() → Success message
  • createWarning() → Warning message
  • createError() → Error message
  • createInfo() → Info message
  • createMessageWithImage() → Custom image message
  • setDefultAutoTimeOutForAll() → Set default timeout

Themes

You can apply different themes using predefined classes:

  • theme-default
  • theme-success

  • theme-error

API

  • new popUpMassge(time) → Initialize system with default timeout
  • setDefultAutoTimeOutForAll(time) → Set global timeout
  • createSuccess(msg, replace, time)
  • createError(msg, replace, time)
  • createWarning(msg, replace, time)
  • createInfo(msg, replace, time)
  • createMassage(msg, replace, time)
  • createMessageWithImage(msg, imgPath, title, replace, time)
